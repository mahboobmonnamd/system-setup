Core

Ghostty

Your terminal: Catppuccin Latte, JetBrains Mono, Option-as-Alt for fzf. Quake dropdown from anywhere.

Open Ghostty app · quake: Cmd+Opt+`

Keybinds

KeysAction
Cmd+Opt+`Toggle quake-style quick terminal (global)
Cmd+↑Jump to previous prompt (shell integration)
Cmd+↓Jump to next prompt
Option = AltNeeded for Alt+C fzf directory jump

Agent-first work: cmux + Herdr. Classic long-lived shell: tmux. Use Ghostty quake for one-off commands without leaving the browser/IDE.

cmux reads this same file for chrome sizes: surface-tab-bar-font-size = 14 (pane tabs, max) and sidebar-font-size = 14. After stow: Cmd+Shift+, (or cmux reload-config).

Common flows

  1. Quick command without context-switching

    From any app: Cmd+Opt+` → run command → same key to hide.

  2. Scroll to the last command’s output

    Cmd+↑ jumps prompt-to-prompt — faster than hunting scrollback.

  3. Deep work session

    Full Ghostty window → tmux / sesh for classic work, or cmux → hr for agents → leave quake for interruptions.

Reach for this instead

  • Cmd-Tab to terminal for one command→Cmd+Opt+`
  • Scroll forever to find output→Cmd+↑ prompt jump
  • Many bare terminal windows→cmux + Herdr (agents) or Ghostty + tmux

Drills

  • From Safari (or any app), open quake, run pwd, hide it — without Cmd-Tab. Cmd+Opt+` both ways.
  • Run three commands in a row, then Cmd+↑ until you’re at the first. Feel prompt boundaries.
  • Confirm Alt+C opens fzf directories (Option-as-Alt). If it types ç instead, Option isn’t Alt.
