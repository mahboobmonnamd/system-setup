Common flows

  1. Land in a project fast

    z + a unique fragment of the folder name → you’re there. No cd ~/Developer/….

  2. Replay a past command

    Ctrl+R → type a few words → Enter. Prefer this over arrowing through history.

  3. Build a command with paths

    Type the command, Ctrl+T to insert a file, or Alt+C to jump first.

  4. Checkout without remembering the branch

    gco-fzf → fuzzy pick → Enter.

Reach for this instead

  • cd ~/Developer/foo/bar→z bar
  • history | grep …→Ctrl-R
  • ls -la→ll
  • find . -name→fd / Ctrl-T
  • git checkout <branch>→gco-fzf

Drills

  • Jump to this repo with z system-setup (or a shorter fragment). No tab-completing a long path.
  • Find any past brew or make command with Ctrl+R and re-run it. Type 2–3 distinctive chars, not the whole line.
  • From anywhere, insert a nested file path into bat using only Ctrl+T. Preview should show bat on the right.
