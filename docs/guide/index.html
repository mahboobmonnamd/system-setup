How to practice

  1. One page per session

    Open a tool page. Run the drills without looking at the mouse. Close the page and repeat from memory.

  2. Replace old habits

    Each page has “reach for this instead” pairs — force the new path for a week.

  3. Print if it helps

    Pages are print-friendly. Park a keybind sheet next to the keyboard for the first few days.

Install / bootstrap stays in the repo README. This guide only covers what you type every day.
