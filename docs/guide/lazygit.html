lazygit

Full git workflow as a TUI — status, stage, commit, branches, remotes — without juggling flags.

Launch lg · lazygit · in nvim: Space g g

Keybinds

KeysAction
1–5Jump panels: status / files / branches / commits / stash
Tab / Shift+TabNext / previous panel
j / kMove selection
SpaceToggle stage file / hunk
aStage all
cCommit
Shift+PPush
pPull
EnterEnter file / view commit
dDiscard change (confirm)
nNew branch (from branches panel)
SpaceCheckout branch (branches panel)
/Filter / search in panel
xMenu of available actions for selection
?Cheatsheet (built-in)
qQuit

Diffs use delta (Latte). Press ? inside lazygit whenever you forget a key — then come back here to drill the core loop.

Common flows

  1. Stage hunk → commit → push

    Files panel → select file → Enter → Space on hunks → Esc → c message → Shift+P.

  2. Switch branch

    3 (branches) → / filter → Space to checkout.

  3. Inspect recent history

    4 (commits) → j/k → Enter for diff.

Reach for this instead

  • git status && git add -p→lg → Space on hunks
  • git log --oneline --graph→lg → panel 4
  • git checkout -b …→lg → 3 → n

Drills

  • Make a tiny edit, open lg, stage with Space, commit with c, quit with q — under 30 seconds. Don’t touch the mouse.
  • From the commits panel, open a commit and close it without quitting lazygit. 4 → Enter → Esc.
  • Open lazygit from nvim via Space gg, push if needed, quit back to the buffer. Same keys as shell lg.
