Core

Herdr + cmux

Agent-first stack: cmux is the terminal, Herdr is the multiplexer. Prefix is Ctrl+a — same muscle memory as tmux.

Launch hr · cmux Cmd+Shift+H · hrr reload

Layers

LayerToolJob
Terminalcmux (or Ghostty)Tabs, agent notifications, prompt jump
MultiplexerHerdrPanes, detach, agent state (working / blocked / idle)

Do not run tmux inside Herdr for agent work — pick one multiplexer. Classic shell sessions can still use tmux under Ghostty.

Common flows

  1. Start the agent day

    Open cmux → Cmd+Shift+H (or hr) → first time make herdr-plugins → run Claude / Codex in panes → detach with Ctrl+a d.

  2. Jump when an agent needs you

    Cmd+Shift+U in cmux, or scan Herdr sidebar for blocked.

  3. After editing config

    hrr (or Ctrl+a r) — no restart needed for most keys.

Reach for this instead

  • tmux inside cmux for agents→Herdr inside cmux
  • Switch tabs hunting for a waiting agent→Cmd+Shift+U / Herdr sidebar
  • Quit the terminal and lose agents→Ctrl-a d, reopen, hr

Drills

  • From cmux, start Herdr, split right + down, move with only Ctrl+hjkl (no prefix). Same chord as tmux + nvim.
  • Detach, quit cmux, reopen, hr — agents still there. That’s the point of Herdr.
  • Trigger an agent notification, jump with Cmd+Shift+U. Terminal chrome, not multiplexer.
