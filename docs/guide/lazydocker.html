TUIs

lazydocker

Containers, images, volumes, and logs in one TUI. Docker CLI talks to Colima on this setup.

Launch lzd · lazydocker · first: colima start

Keybinds

KeysAction
TabCycle panels (containers / images / volumes…)
j / kMove selection
EnterSelect / expand
dRemove container/image (confirm)
sStop container
rRestart container
aAttach / exec into container (context menu)
lView logs
eExec shell in container
[ / ]Previous / next tab in side views
xMenu of actions
?Help
qQuit

If the UI is empty: colima start then docker ps to confirm the daemon, then lzd again.

Common flows

  1. Tail logs for a misbehaving container

    lzd → select container → l (or logs pane) → watch → q when done.

  2. Shell into a container

    Select → e / attach action → work → exit shell → still in lazydocker.

  3. Prune junk images

    Images panel → select dangling/unused → d carefully.

Reach for this instead

  • docker ps && docker logs -f→lzd → select → l
  • docker exec -it … sh→lzd → e
  • docker system df / prune guesswork→lzd images/volumes panels

Drills

  • Start Colima, run any container (docker run -d nginx), open lzd, find it, open logs, stop it. All from the TUI.
  • Without looking at ?, cycle panels with Tab and land back on containers. Muscle for panel awareness.

Alias: lzd in stow/zsh/.config/zsh/aliases.zsh · runtime: Colima + docker CLI (see README)
