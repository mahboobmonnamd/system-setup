Notes

Obsidian

Your notes live in a private vault at ~/Documents/Brain (not in this repo). Day-to-day how-to is in the vault’s GUIDE.md — this page is the short shell + shortcut cheat sheet.

Try obs · odaily · ocd · obsync

From the terminal

CommandWhat it does
obsOpen the Brain vault in Obsidian
odailyOpen today’s daily note (creates it if needed)
ocdJump into the vault folder (handy before starting an agent)
obsyncSave and push the vault to GitHub now
make obsidian-syncSame backup, run from this repo
make obsidian-sync-installTurn on automatic hourly backup

To use a different vault path, set OBSIDIAN_VAULT in ~/.config/zsh/env.local.zsh.

Useful shortcuts in Obsidian

KeysWhat it does
Cmd+NCreate a note from a template
Cmd+Shift+DOpen today’s daily note
Cmd+Shift+WOpen this week’s note
Cmd+PCommand palette

Working with agents

AgentInstruction filesUse for
ClaudeCLAUDE.md + AGENTS.mdPersonal notes (personal / shared)
BobBOB.md + AGENTS.mdWork notes (work / shared)

Run ocd first so the agent opens inside the vault. Drafts land in _agent/inbox until you file them.

Everyday flow

  1. Start the day

    obs → open Home → Cmd+Shift+D for today → glance at Inbox.

  2. Ask Claude or Bob for help

    ocd → start the agent there → review _agent/inbox → move finished notes into the right folders.

  3. Backup before you leave

    Run obsync, or let the hourly backup handle it.

Prefer this

  • Editing the old iCloud copy→only ~/Documents/Brain
  • Keeping notes only on one Mac→private GitHub backup (obsync)
  • Mixing personal and work for agents→set domain and follow CLAUDE / BOB

Quick checks

  • ocd then pwd should show ~/Documents/Brain.
  • In Obsidian, Cmd+N → Decision template → file should appear under 09-Decisions.
  • make obsidian-sync should either say nothing to commit or push cleanly.
