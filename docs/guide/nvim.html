Neovim (LazyVim)

Space is the leader — press it and a menu shows everything. Learn the handful below first; discover the rest from which-key.

Launch nvim · nvim . · $EDITOR

Keybinds (yours + LazyVim essentials)

Common flows

  1. Open a file by name

    Space Space → type fragments → Enter. Prefer this over the explorer for known files.

  2. Find a string, jump, edit

    Space / → pick match → edit → Space w to save.

  3. Git without leaving the editor

    Space g g → lazygit overlay → stage/commit → quit back to nvim.

  4. Leave insert without stretching to Esc

    Type j k from home row.

Reach for this instead

  • :e path/to/file→Space Space
  • Esc (far key)→jk
  • :w→Space w
  • Mouse to click another pane→Ctrl-h/j/k/l

Drills

  • Open nvim in this repo. Open three files with only Space Space, flip between them with Shift+H/L. No mouse tabs.
  • Grep for a known string with Space /, jump, change one word, save with Space w. Exit insert via jk.
  • Press Space and linger — read the which-key groups once. Open lazygit with Space gg, quit, back to editing. Same lg muscle, inside the editor.
