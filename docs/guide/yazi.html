yazi

Terminal file manager. The y wrapper cds your shell into the directory you browsed when you quit.

Launch y (preferred) · yazi (no cd-on-quit)

Keybinds

KeysAction
h / lUp directory / enter directory or open
j / kDown / up in list
EnterOpen file / enter dir
SpaceToggle select
vVisual / select mode
yYank (copy) selection
xCut selection
pPaste
dTrash / delete
rRename
.Toggle hidden files
zzoxide jump (if enabled)
~Go home
/Find / filter
qQuit — shell cds here when launched via y

Common flows

  1. Browse then work in that folder

    y → navigate with hjkl → q → prompt is now in that directory.

  2. Peek then open in nvim

    Navigate onto a file → Enter (opens with configured opener) or quit and nvim the path.

  3. Bulk move

    Space select files → x cut → navigate to dest → p paste.

Reach for this instead

  • cd; ls; cd; ls…→y → q
  • open Finder for one rename→y → r
  • mv a/b c/d with long paths→y → x → p

Drills

  • From home, y into Developer/system-setup, quit with q, confirm pwd. Must use the y function, not raw yazi.
  • Toggle hidden files with ., find a dotfile, toggle back. Same key both ways.

Wrapper: y() in stow/zsh/.config/zsh/functions.zsh
