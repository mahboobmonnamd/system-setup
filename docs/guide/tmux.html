tmux

Sessions that survive closing the window. Prefix is Ctrl+b — press it, release, then the next key. Move panes with Ctrl+a/w/s/d (WASD). Manage sessions from the shell with tn/ta/tl/tk or tm (sesh).

Launch tn work · ta work · tm · Ctrl+b T

Sessions (shell)

CommandAction
tn <name>New named session (tmux new -s)
ta <name>Attach to session (tmux attach -t)
tlList sessions
tk <name>Kill session by name
tksvKill the tmux server (all sessions)
tmsesh fuzzy picker from the shell (sessions + zoxide)
tmuxconfEdit ~/.config/tmux/tmux.conf

WASD layout: a left · w up · s down · d right. Prefix is Ctrl+b so Ctrl+a can mean “left”. In sesh (Ctrl+b T or tm): Ctrl+a all · Ctrl+t tmux · Ctrl+g configs · Ctrl+x zoxide · Ctrl+f find · Ctrl+d kill.

Common flows

  1. Start a named project session

    tn api (or tm / Ctrl+b T → pick a zoxide dir). Detach with Ctrl+b Ctrl+d, return with ta api.

  2. Editor + shell side by side

    Ctrl+b | → one pane nvim, other shell. Move with Ctrl+a/d. Resize with Ctrl+b Alt+a/d.

  3. Leave without killing work

    Ctrl+b Ctrl+d → close Ghostty. Later: ta <name>, tm, or tmux attach. Continuum auto-saves every 15 min and restores on start.

Reach for this instead

  • Many Ghostty tabs→tmux windows (Ctrl-b c / 1..9)
  • tmux new -s … / attach -t …→tn / ta / tm
  • cd then reopen tools→Ctrl-b T or tm (sesh)
  • Mouse to switch nvim ↔ shell→Ctrl-a/w/s/d (WASD)

Drills

  • Create tn drill, split right, split down, navigate every pane with only Ctrl+awsd. No mouse, no prefix for movement.
  • Detach, close the terminal, reopen, ta drill — confirm panes are still there. That’s the point of tmux.
  • From a bare shell, run tm and jump into a project you haven’t typed a path for. Same picker as Ctrl+b T.
