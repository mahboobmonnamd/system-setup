tmux

Sessions that survive closing the window. Prefix is Ctrl+a — press it, release, then the next key. Manage sessions from the shell with tn/ta/tl/tk or tm (sesh). For agent-first work use Herdr + cmux instead (same prefix).

Launch tn work · ta work · tm · Ctrl+a T

Active pane border is peach; press Ctrl+a for a peach PREFIX pill (same cues as Herdr). Ctrl+a 1…9 switches windows. Pane jump is separate: Ctrl+a q, then a bare digit (display-panes eats that key — windows stay put). Mouse is on — drag a border to resize.

Claude Code / Codex: Shift+Enter for newline needs tmux extended-keys (already in this repo). After stow: tmux kill-server then tn … again — a plain Ctrl+a r is not enough. Fallback anytime: Ctrl+J or \ then Enter.

In sesh (Ctrl+a T or tm): Ctrl+a all · Ctrl+t tmux · Ctrl+g configs · Ctrl+x zoxide · Ctrl+f find · Ctrl+d kill.

Common flows

  1. Start a named project session

    tn api (or tm / Ctrl+a T → pick a zoxide dir). Detach with Ctrl+a d, return with ta api.

  2. Editor + shell side by side

    Ctrl+a | → one pane nvim, other shell. Move with Ctrl+h/l. Resize with Ctrl+a H/L.

  3. Leave without killing work

    Ctrl+a d → close Ghostty. Later: ta <name>, tm, or tmux attach. Continuum auto-saves every 15 min; restore manually with Ctrl+a Ctrl+r.

Reach for this instead

  • Many Ghostty tabs→tmux windows (Ctrl-a c / 1..9)
  • tmux new -s … / attach -t …→tn / ta / tm
  • cd then reopen tools→Ctrl-a T or tm (sesh)
  • Mouse to switch nvim ↔ shell→Ctrl-h/j/k/l

Drills

  • Create tn drill, split right, split down, navigate every pane with only Ctrl+hjkl. No mouse, no prefix for movement.
  • Detach, close the terminal, reopen, ta drill — confirm panes are still there. That’s the point of tmux.
  • From a bare shell, run tm and jump into a project you haven’t typed a path for. Same picker as Ctrl+a T.
