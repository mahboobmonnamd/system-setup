tmux

Sessions that survive closing the window. Prefix is Ctrl+a — press it, release, then the next key.

Launch tmux · tmux attach · Ctrl+a T (sesh)

Keybinds

KeysAction
Ctrl+a cNew window
Ctrl+a 1…9Switch window by number
Ctrl+a |Split pane right (keeps cwd)
Ctrl+a -Split pane down (keeps cwd)
Ctrl+h/j/k/lMove across panes and nvim splits (no prefix)
Ctrl+a Tsesh picker — sessions + zoxide dirs
Ctrl+a dDetach (session keeps running)
Ctrl+a rReload tmux.conf
Ctrl+a IInstall/update TPM plugins
Ctrl+a EnterCopy mode (vi keys)
v / yIn copy mode: begin selection / yank
Ctrl+a Ctrl+aSend a literal Ctrl-a

In sesh (Ctrl+a T): Ctrl+a all · Ctrl+t tmux only · Ctrl+x zoxide · Ctrl+d kill session.

Common flows

  1. Start a project session

    Ctrl+a T → pick a zoxide dir → sesh creates/attaches a session there.

  2. Editor + shell side by side

    Ctrl+a | → one pane nvim, other shell. Move with Ctrl+h/l.

  3. Leave without killing work

    Ctrl+a d → close Ghostty. Later: tmux attach or sesh again. Continuum auto-saves every 15 min.

Reach for this instead

  • Many Ghostty tabs→tmux windows (Ctrl-a c / 1..9)
  • cd then reopen tools→Ctrl-a T (sesh)
  • Mouse to switch nvim ↔ shell→Ctrl-h/j/k/l

Drills

  • Create a window, split right, split down, then navigate every pane with only Ctrl+hjkl. No mouse, no prefix for movement.
  • Detach, close the terminal, reopen, tmux attach — confirm panes are still there. That’s the point of tmux.
  • Open sesh and jump into a project you haven’t typed a path for. Ctrl+a T then filter by name.
